Περιγραφή της υλοποίησης:
Αρχικά η υλοποίηση ξεκινάει με Constrained Delaunay Triangulation (CDT).
Έχουμε υλοποιήσει μια συνάρτηση brute_force_steiner_insertion() η οποία ελέγχει ποια θα είναι η βέλτιστη λύση ελέγχοντας ποια από τις υλοποιήσεις εισαγωγής steiner point θα έχει τα λιγότερα insertions.
Αφού ελέγξει όλες τις υλοποιήσεις και βρει τη βέλτιστη, τότε εφαρμόζει τη συνάρτηση apply_best_sequence() η οποία προσθέτει τα steiner points χρησιμοποιώντας τη βέλτιστη υλοποίηση.

Για το δεύτερο παραδοτέο, η συνάρτηση αυτή πλέον τρέχει μόνο στην περίπτωση της επιλογής delaunay: false στο αρχείο εισόδου.

Για την εισαγωγή των steiner points έχουν υλοποιηθεί οι εξής μέθοδοι:

-> Εισαγωγή steiner point στο μέσο της μεγαλύτερης ακμής ενός αμβλυγωνίου τριγώνου.
-> Εισαγωγή steiner point στο περίκεντρο (circumcenter) ενός αμβλυγωνίου τριγώνου. Αν το περίκεντρο είναι εκτός του region boundary, το steiner point γίνεται το βαρύκεντρο(centroid).
-> Εισαγωγή steiner point στο βαρύκεντρο.
-> Εισαγωγή steiner point στο σημείο τομής της προβολής της αμβλείας γωνίας με την απέναντι πλευρά.
-> Εισαγωγή steiner point στο κέντρο κυρτού πολυγώνου από γειτωνικά αμβλυγώνια τρίγωνα.
-> Εισαγωγή steiner point σε περιοχή γύρω από το βαρύκεντρο.

Σε κάθε εκτέλεση του εκτελέσιμου αρχείου θα δημιουργείται ένα αρχείο output.json που θα περιέχει:

1. content_type: Μια συμβολοσειρά "CG_SHOP_2025_Solution".
2. instance_uid: Ένας μοναδικός αναγνωριστικός κωδικός της περίπτωσης (string).
3. steiner_points_x: Μια λίστα με τις x-συντεταγμένες των σημείων Steiner. Κάθε συντεταγμένη μπορεί να είναι ένας ακέραιος ή ένα κλάσμα σε μορφή συμβολοσειράς.
4. steiner_points_y: Μια λίστα με τις y-συντεταγμένες των σημείων Steiner, διαμορφωμένες όπως και οι steiner_points_x.
5. edges: Μια λίστα από ακμές, όπου κάθε ακμή αναπαρίσταται ως ένα ζεύγος ακεραίων που αντιστοιχούν σε δείκτες σημείων.
6. obtuse_count: Ο αριθμός των αμβλυγώνιων τριγώνων.
7. method: Η μέθοδος που χρησιμοποιήθηκε.
8. parameters: Οι παράμετροι που επιλέχθηκαν.
9. randomization: Boolean τιμή που δείχνει αν θα προστεθούν τυχαία σημεία στην τριγωνοποίηση

Για τα edges χρησιμοποιήθηκε map το οποίο αντιστοιχεί τα vertices(κορυφές) με ένα δείκτη σημείου.

Από το πρώτο παραδοτέο, έχουν βελτιωθεί τα εξής:

Προσθήκη συνάρτησης εισαγωγής σημείου steiner στο κέντρο πολυγώνου γειτονικών αμβλυγώνιων, με την χρήση της insert_no_flip().
Προσθήκη ξεχωριστής συνάρτησης εισαγωγής σημείου steiner στο κεντροειδές (προηγουμένως αυτό γινόταν μόνο σε περίπτωση που το περίκεντρο ήταν εκτός region boundary).
Μετατροπή της συνάρτησης εισαγωγής περίκεντρου ώστε να αφαιρείται η ακμή απέναντι από την αμβλεία πριν την εισαγωγή του περίκεντρου.
Προσθήκη του region boundary στα constraints διότι υπήρχαν προβλήματα αν δεν το συμπεριλάβουμε.
Μετατροπή των συναρτήσεων ώστε να μπαίνει το σημείο steiner σε δοσμένο face (προηγουμένως έμπαινε στο πρώτο αμβλυγώνιο που έβρισκε στην τριγωνοποίηση).

Προσομοιωμένη Ανόπτηση

Η υλοποίηση της Προσομοιωμένης Ανόπτησης βρίσκεται στα αρχεία simulated_annealing.cpp και simulated_annealing.h στον φάκελο includes/utils

Η συνάρτηση compute_energy υπολογίζει την ενέργεια της τριγωνοποίησης με βάση τις αμβλείες και τον αριθμό των steiner.

Η συνάρτηση choose_steiner χρησιμοποιείται για την τυχαία επιλογή μεθόδου εισαγωγής σημείου steiner.

Η συνάρτηση simulated_annealing_opt λειτουργεί ως εξής:

Όσο η θερμοκρασία είναι >= 0 και υπάρχουν αμβλυγώνια, βρίσκει όλα τα αμβλυγώνια τρίγωνα.

Για κάθε αμβλυγώνιο τρίγωνο, διαλέγει τυχαία μια από τις 5 μεθόδους και την χρησιμοποιεί σε ένα αντίγραφο της τριγωνοποίησης.

Έπειτα υπολογίζει την νέα ενέργεια. Αν βελτιώθηκε η ενέργεια δεχόμαστε την νεα τριγωνοποίηση αλλιώς την δεχόμαστε με την πιθανότητα e^{-ΔΕ/Τ}.

Ant Colony 

heuristic: Υπολογίζει τις τιμές h για κάθε μέθοδο ανάλογα με το radius to height ratio

improve triangulation: Υπολογίζει τις πιθανότητες με βάση τις φερομόνες και τις τιμές h και προσθέτει ένα σημείο steiner με την κατάλληλη μέθοδο

evaluate triangulation: Υπολογίζει την ενέργεια της τριγωνοποίησης

update pheromones: Εφαρμόζει εξάτμιση στις φερομόνες και ελέγχει για ενίσχυση στις φερομόνες ανάλογα με τις μεθόδους που χρησιμοποίησαν τα μυρμήγκια

ant colony optimization: Λειτουργεί ως εξής:

Για κάθε κύκλο, βρίσκει όλα τα αμβλυγώνια.

Για κάθε μυρμήγκι, γίνεται η ανάθεση ενός τυχαίου αμβλυγωνίου και εφαρμόζεται η improve triangulation

Έπειτα την κάνει evaluate. Αν βελτίωσε, το μυρμήγκι μπαίνει στα μυρμήγκια που βελτίωσαν.

Μόλις τελειώσουν όλα τα μυρμήγκια, προσπαθούνε όλα να μπουν στην τριγωνοποίηση.

Μπαίνουν ένα ένα, και κάθε φορά γίνεται evaluate η τριγωνοποίηση, ώστε να ελεγχθούν τυχόν conflicts. Αν χειροτερέυσει η ενέργεια, δεν μπαίνει στην τριγωνοποίηση
